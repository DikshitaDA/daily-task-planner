# Daily Task Planner

A lightweight productivity web application designed to help users organize daily goals, prioritize checklists, and track pending and completed tasks.

## Live Demo

- Live Application: https://dailytaskplanner1.netlify.app/
- GitHub Repository: https://github.com/DikshitaDA/daily-task-planner

## Tech Stack

- Frontend: HTML5, CSS3, JavaScript
- Storage: LocalStorage for client-side data persistence
- Deployment: Netlify

## Key Features

- Task Management: Create, view, mark as complete, and delete daily tasks.
- Persistent State: Utilizes browser localStorage so tasks remain saved even after a page refresh.
- Status Filtering: Quickly filter tasks by All, Active, and Completed.
- Clean Interface: Minimalist and distraction-free design for everyday planning.

## Local Setup

1. Clone the repository:
git clone https://github.com/DikshitaDA/daily-task-planner.git
cd daily-task-planner

2. Run locally:
Open index.html directly in your browser.
